| # | Items | Finding | Resolution |
|---|---|---|---|
| F1 | CHK009 | The plan cancelled a run nobody reads when the service stops (research R17, first version). A run with a reader is not cut by an ordinary stop today, because the service waits for its connection. So a console run would have been cut in the middle of a step at every deploy, which is the commonest way an approved action could take effect without its result being recorded. The spec's edge case said only that completed steps are kept. | FR-021 and two edge cases: stopped in the ordinary way, the service treats each console run as if a stop had been asked for it and waits for the step under way.
